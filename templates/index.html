Penjelasan Model

Apa itu Linear Regression?

Linear Regression adalah algoritma machine learning supervised yang memodelkan hubungan linear antara variabel independen (fitur) dan variabel dependen (target). Model ini mencari garis (atau hyperplane) terbaik yang meminimalkan jarak antara nilai aktual dan nilai prediksi.

Rumus Model

Å· = Î²â‚€ + Î²â‚ xâ‚ + Î²â‚‚xâ‚‚ + ... + Î²â‚™xâ‚™

Di mana Å· adalah prediksi, Î²â‚€ adalah intercept, and Î²â‚ ...Î²â‚™ adalah koefisien untuk setiap fitur.

Kelebihan

  • Interpretable: Koefisien menunjukkan arah dan kekuatan pengaruh setiap fitur.
  • Cepat: Waktu training sangat singkat, cocok untuk dataset kecil.
  • Baseline: Sering digunakan sebagai model dasar untuk perbandingan.

Keterbatasan

  • Hanya menangkap hubungan linear antar variabel.
  • Sensitif terhadap outlier yang dapat mempengaruhi garis regresi.
  • Asumsi multikolinearitas rendah antar fitur.

Apa itu Random Forest?

Random Forest adalah algoritma ensemble learning yang menggabungkan banyak Decision Tree untuk menghasilkan prediksi yang lebih akurat dan stabil. Setiap tree dilatih dengan subset data acak (bagging), dan hasil akhirnya merupakan rata-rata dari semua tree.

Cara Kerja

Å· = (1/N) Ã— Î£ tree_i(x) untuk i = 1...N

Di mana N adalah jumlah tree (100 dalam model ini), dan tree_i(x) adalah prediksi dari tree ke-i.

Konfigurasi Model

  • n_estimators = 100: Jumlah decision tree dalam ensemble.
  • max_depth = 8: Kedalaman maksimum setiap tree.
  • min_samples_split = 3: Minimum sampel untuk membagi node.
  • min_samples_leaf = 2: Minimum sampel pada setiap leaf.

Kelebihan

  • Non-linear: Mampu menangkap hubungan non-linear yang kompleks.
  • Robust: Tidak mudah overfitting berkat mekanisme bagging.
  • Feature Importance: Otomatis menghitung tingkat kepentingan setiap fitur.

Keterbatasan

  • Kurang interpretable dibandingkan Linear Regression.
  • Waktu training lebih lama untuk dataset besar.
  • Membutuhkan tuning hyperparameter yang tepat.

Apa itu XGBoost?

XGBoost adalah algoritma gradient boosting berbasis ensemble yang membangun pohon keputusan secara bertahap. Setiap iterasi belajar dari error model sebelumnya sehingga mampu menangkap pola non-linear dengan regularisasi yang lebih kuat.

Konfigurasi Model

  • n_estimators = 200: Jumlah maksimum boosting round.
  • max_depth = 4: Pohon dibuat dangkal untuk mengurangi overfitting pada dataset kecil.
  • learning_rate = 0.05: Pembelajaran dibuat konservatif agar generalisasi lebih stabil.
  • subsample dan colsample_bytree = 0.8: Sampling baris dan fitur untuk menekan variance.
  • reg_alpha dan reg_lambda: Regularisasi L1/L2 untuk mengendalikan kompleksitas model.

Kelebihan

  • Regularisasi: Lebih tahan overfitting dibanding ensemble pohon biasa.
  • Early stopping: Training berhenti saat performa validasi tidak membaik.
  • Feature Importance: Menunjukkan fitur yang paling berkontribusi terhadap prediksi.

Metrik Evaluasi

  • MAE (Mean Absolute Error): Rata-rata selisih absolut antara prediksi dan aktual. Semakin kecil semakin baik.
  • RMSE (Root Mean Squared Error): Akar kuadrat dari rata-rata kuadrat kesalahan. Lebih sensitif terhadap outlier.
  • RÂ² Score: Proporsi variansi data yang bisa dijelaskan oleh model. Nilai 1.0 = sempurna, nilai negatif = lebih buruk dari rata-rata.

Fitur yang Digunakan

Kedua model menggunakan 9 variabel ekonomi makro Indonesia sebagai fitur input: Tahun, Kuartal, Populasi, Inflasi, Suku Bunga, Pengangguran, Investasi, Ekspor, dan Konsumsi Rumah Tangga.

Mekanisme Comparison Model (Perbandingan Model)

Fitur Perbandingan Model di aplikasi ini dirancang untuk mengevaluasi dan membandingkan performa dari Linear Regression dan Random Forest secara berdampingan. Hal ini dilakukan karena tidak ada algoritma machine learning tunggal yang cocok untuk semua jenis data (No Free Lunch Theorem).

  • Testing Simultan: Saat dataset diperbarui, sistem akan melatih ulang (retrain) kedua model secara bersamaan menggunakan dataset yang sama (dengan train-test split 80:20).
  • Penentuan Best Model: Sistem secara otomatis mengevaluasi metrik MAE, RMSE, dan RÂ² Score dari kedua model pada set pengujian. Model dengan nilai RÂ² Score tertinggi dinobatkan sebagai "Best Model".
  • Dual Prediction: Pada halaman prediksi perbandingan, input pengguna akan dimasukkan ke dalam kedua model. Hasil dari "Best Model" akan disorot sebagai rekomendasi utama, memberikan perspektif hasil dari dua pendekatan yang berbeda (linear vs non-linear).
