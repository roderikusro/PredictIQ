Penjelasan Model

Apa itu Linear Regression?

Linear Regression adalah algoritma machine learning supervised yang memodelkan hubungan linear antara variabel independen (fitur) dan variabel dependen (target). Model ini mencari garis (atau hyperplane) terbaik yang meminimalkan jarak antara nilai aktual dan nilai prediksi.

Rumus Model

ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ

Di mana ŷ adalah prediksi, β₀ adalah intercept, dan β₁...βₙ adalah koefisien untuk setiap fitur.

Kelebihan

  • Interpretable: Koefisien menunjukkan arah dan kekuatan pengaruh setiap fitur.
  • Cepat: Waktu training sangat singkat, cocok untuk dataset kecil.
  • Baseline: Sering digunakan sebagai model dasar untuk perbandingan.

Keterbatasan

  • Hanya menangkap hubungan linear antar variabel.
  • Sensitif terhadap outlier yang dapat mempengaruhi garis regresi.
  • Asumsi multikolinearitas rendah antar fitur.

Apa itu Random Forest?

Random Forest adalah algoritma ensemble learning yang menggabungkan banyak Decision Tree untuk menghasilkan prediksi yang lebih akurat dan stabil. Setiap tree dilatih dengan subset data acak (bagging), dan hasil akhirnya merupakan rata-rata dari semua tree.

Cara Kerja

ŷ = (1/N) × Σ tree_i(x) untuk i = 1...N

Di mana N adalah jumlah tree (100 dalam model ini), dan tree_i(x) adalah prediksi dari tree ke-i.

Konfigurasi Model

  • n_estimators = 100: Jumlah decision tree dalam ensemble.
  • max_depth = 8: Kedalaman maksimum setiap tree.
  • min_samples_split = 3: Minimum sampel untuk membagi node.
  • min_samples_leaf = 2: Minimum sampel pada setiap leaf.

Kelebihan

  • Non-linear: Mampu menangkap hubungan non-linear yang kompleks.
  • Robust: Tidak mudah overfitting berkat mekanisme bagging.
  • Feature Importance: Otomatis menghitung tingkat kepentingan setiap fitur.

Keterbatasan

  • Kurang interpretable dibandingkan Linear Regression.
  • Waktu training lebih lama untuk dataset besar.
  • Membutuhkan tuning hyperparameter yang tepat.

Metrik Evaluasi

  • MAE (Mean Absolute Error): Rata-rata selisih absolut antara prediksi dan aktual. Semakin kecil semakin baik.
  • RMSE (Root Mean Squared Error): Akar kuadrat dari rata-rata kuadrat kesalahan. Lebih sensitif terhadap outlier.
  • R² Score: Proporsi variansi data yang bisa dijelaskan oleh model. Nilai 1.0 = sempurna, nilai negatif = lebih buruk dari rata-rata.

Fitur yang Digunakan

Kedua model menggunakan 9 variabel ekonomi makro Indonesia sebagai fitur input: Tahun, Kuartal, Populasi, Inflasi, Suku Bunga, Pengangguran, Investasi, Ekspor, dan Konsumsi Rumah Tangga.
